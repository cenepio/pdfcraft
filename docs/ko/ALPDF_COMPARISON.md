# 알PDF 대비 동일 조건 비교시험

| 시험 | 검증 내용 |
|---|---|
| 한글 문구 교체 | '보험가입금액' 등 한글 편집 후 재추출 및 시각적 보존 |
| 금액·날짜 수정 | `1,000,000,000원` → `1,500,000,000원` 자리수 및 겹침 |
| 표 안의 한글 | 열·행·테두리·줄바꿈·행간·위치 유지 |
| 한글+영어+숫자 | Unicode·글꼴 매핑/유실 글리프 검출 |
| 폰트 서브셋 PDF | 없는 글리프를 조용히 대체하지 않고 오류 처리 |
| Windows IME | 자모 조합, 삭제, 붙여넣기, 입력 취소 |
| PDF 저장·재열기 | 주변 객체·그래픽 손상 및 텍스트 정확도 |
| 스캔·서명 PDF | 미지원 동작에 대해 명확한 경고와 원본 보존 |

서로 동일한 Windows 장치, 동일 문서, 동일 서체 환경에서 알PDF와 PdfCraft를 비교합니다. 실제 고객 정보가 있는 PDF는 공개 저장소에 커밋하지 않습니다.

현 시점 **비교 결과 미측정**. 객관적 합격 전 알PDF보다 우수하다고 주장하지 않습니다.
